## Key Decisions
- **Distroless over Slim**: Switched to `gcr.io/distroless/cc-debian12` for the final stage to minimize attack surface (no shell/package manager).
- **Shadow Router Pattern**: Kept the `Router<AppState>` type explicit during construction and converted to `Router<()>` using `.with_state()` only at the final assembly point.
- **Audit Ledger Exposure**: Decided to expose the existing `audit_ledger_global` table to provide better visibility for enterprise compliance audits.

## Lessons Learned
- Axum 0.7 `with_state` consumes the router and returns a `Router<()>`. Any additional merging must be done carefully regarding state types.
- `sqlx` migrations via raw queries in `init_db` need careful "duplicate column" checks if not using a formal migration tool.
