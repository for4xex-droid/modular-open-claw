脅威「Rust Agent OS」の心理的定番を OpenFang が先取り。OS 基盤で戦わず、経済圏+体験で戦う方針は前回から不変で正しい

最大の強み (Top Moats)

  • 経済が OS 契約 — Stripe→Nurture coin-charge が OXP fail-closed + DLQ 再送まで閉じた（OP-060/061）
  • 形式検証された経済保存則 — TLA+ は Framework 競合が持たない
  • A2C 恩返しナラティブ — コンパニオン市場の「課金」ではなく「AI が返す」差別化
  • ローンチ可能なコードベース — deep-scan 0 / テスト数千 / ADR 57

最大のリスク (Critical Gaps)

  • ユーザー 0 / PMF 未検証 — V-3=2 が総合の天井
  • 本番課金 env 未反映 — コードは完成、Human ゲートのみ
  • バスファクター ≈ 1 — ドキュメントは厚いが人的冗長性なし
  • Agent OS 語彙の先取り競争 — OpenFang 等が心理的定番を取りに来ている
