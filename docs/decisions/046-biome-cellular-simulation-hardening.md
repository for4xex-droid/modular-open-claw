# ADR-046: Biome セルオートマトンの多様性向上と WebGL 描画バグの手硬化

## ステータス
承認済み (Accepted)

## 文脈 (Context)
Biome セルオートマトンにおいて、以下の2つの問題が発生していました。
1. **多様性指数の停滞**: グリッド内で炭素以外の元素が一切隣接セルに拡散せず、活性化したセルが永遠に死滅しない（Decay が存在しない）ため、シミュレーションが即座に活性セルの飽和（熱死状態）を迎え、多様性指数が `0.000` に張り付き進化ランクが上昇しませんでした。
2. **画面左下のグレー正方形バグ**: 
   - 画面左下 1/4（x: 0..64, y: 0..64 の領域）が、半透明なグレーの正方形で覆われていました。
   - 分析の結果、これは WebGL ビューポートのズレではなく、**「1フレームのループ進行中に元素が玉突き状態で超高速（一瞬）で伝播する『芋づる式拡散バグ』」** が真因であることが判明しました。拡散量と可否判定を `next_cells` から逐次引き出していたため、1世代で左下全域が「元素がほぼ0に希釈されて fallback カラー（グレー）になったアクティブな Basic セル」で飽和していました。
   - また、Retina等高DPR環境でのビューポート解像度ズレ、EffectComposerの自動NormalPass生成、およびマウントの1フレーム目で未配置インスタンスが原点 (0,0) に巨大なグレーセルとして描画・残留する Three.js 特有のバグが複合的に絡み合っていました。

## 設計上の意思決定 (Decisions)
本問題を解決するため、以下の変更を決定・実施しました。

### 1. シミュレーション多様性と拡散ロジックの是正 (Rust 側)
- **厳格なダブルバッファリング拡散の実装**: 拡散判定の基準および拡散量の算出には、必ず **`current_cells`（前フレームの状態）の元素量を使用する** ように書き換え、反映先のみを `next_cells` としました。これにより、1フレーム内の玉突き移動が 100% 根絶され、穏やかで物理的に正しい拡散シミュレーションが実現しました。
- **全元素拡散ループ**: 拡散処理を全8元素（0..8）ループ処理に拡張し、すべての元素が隣接セルに均等に拡散・浸透するようにしました。
- **新生セルの自然死（Decay）猶予措置**: 総元素質量が 50 未満に枯渇した場合にセルを休眠に戻す Decay 処理において、**「このフレームで新しく活性化された（前フレーム非アクティブだった）セル」については1フレームの猶予措置を適用** します。これにより、拡散された直後に餓死して生命の伝播がストップしてしまう問題を解消しました。
- **進化テストの調整**: 拡散開始による元素希釈を考慮し、`lib.rs` のテストでの H/O 注入量を 45000 から 60000 に調整しました。

### 2. 描画・ビューポートバグの高度な是正 (React / Three.js 側)
- **dpr={1} の指定**: `BiomeCanvas.tsx` の `Canvas` コンポーネントに `dpr={1}` を明示し、WebGL とポストプロセスのビューポートアスペクト比を完全に一致させました。
- **disableNormalPass の指定**: `BiomePostEffects.tsx` 内の `<EffectComposer>` に `disableNormalPass` を明示し、不要な `NormalPass` のレンダリングとそれに起因する左下への誤投影バグを排除しました。
- **InstancedMesh のマウント時初期化**: `BiomeCellGrid.tsx` に `useEffect` 初期化を追加し、マウントおよびレアリティ変更のタイミングで、全 16,384 個のインスタンス行列のスケールを `0` に初期化しました。これにより、1フレーム目で未配置セルが原点に巨大な不透明グレーの面として残留する Three.js 特有のバグを完全に根絶しました。

## 結果 (Consequences)
- **シミュレーション精度**: 芋づる式拡散が一掃され、元素が穏やかに伝播して他の元素と美しく反応し、枯渇したセルは順次淘汰されるダイナミックな生命サイクルが確立されました。結果として、多様性指数（Shannon）が 0.000 から上昇し、進化ランクが機能するようになりました。
- **描画の一貫性**: 高解像度ディスプレイ環境であっても、画面左下の巨大なグレーの正方形は完全に消失し、セルとエフェクトの正確な位置関係が維持されるようになりました。
- **品質・テスト要件**: 追加した TDD テストケースを含む全 41 個の Rust テストが 100% GREEN パスし、静的解析もすべて通過しています。
