# ADR-030: LoRA Dataset Distillation Pipeline

## Status
Accepted (2026-04-01)

## Context
Aiomeにおける自律的な学習プロセス（Evolution Layer）において、これまでは訓練用データセットが静的な外部ファイルとして扱われていました。しかし、エージェントが長期記憶（Experiences）を継続的に自身のニューラルモデルへと還元するためには、`SoulStore` から記憶を動的に蒸留する安全なETL基盤の確立が急務でした。また同時に、単純な1ターンごとのデータ分割抽出は文脈の破壊（Catastrophic Forgetting）を招く深刻な問題がありました。

## Decision
1. **データ蒸留層（DatasetExtractor）の導入**: 
   LoRA学習の開始直前に `SoulStore` から記憶履歴を取得し、MLX専用の訓練フォーマット（JSONL）へ動的に成形するパイプラインを構築しました。
2. **コンテキスト・ブロックパッキング戦略**:
   破滅的忘却を防止するため、取得した全ターンを個別のJSON行へ分割せず、`\n` で結合した1つの巨大な会話ブロック（`{"text": "<conversation_block>"}`）として出力・維持する構成を採用しました。
3. **スレッドセーフな I/O アイソレーション**:
   並行するAPIリクエストからのファイル競合アクセスを防ぐため、出力ファイルのライフサイクルは一意の UUID (`job_id`) と結合させました。

## Consequences
- **Positive**:
  - 会話の文脈を失うことなく長期間の体験をモデルへと安全に転写（Fine-Tuning）し続けることが可能になりました。
  - プロダクトとしての平行性を保証しつつ、アーキテクチャ上の欠陥（OOM/File Lock）を解決しました。
- **Negative**:
  - 将来的に記憶容量が肥大化した場合、MLモデルのコンテキストウィンドウ上限を超える可能性があるため、後続のPhaseにてさらなる自律的な切り詰め（Sliding Window）機能の実装が必要となります。
