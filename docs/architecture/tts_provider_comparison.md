# TTS Provider 比較表 (2026-03-21)

Aiome の ExpressionEngine に統合を検討している、代表的なオープンソース TTS スタックの比較表です。

| Provider | ライセンス | 商用利用 | 精度 | LoRA / Fine-tuning | Aiome 判定 |
|---|---|---|---|---|---|
| **Voicevox** | GPL2 / LGPL | ⚠️ 注意 | ⭐⭐⭐ | 可能 (別途ツール) | **保留** (商用利用時のライセンスが複雑) |
| **XTTS v2** | Apache 2.0 | ✅ 可能 | ⭐⭐⭐⭐ | 非常に容易 | **最有力候補** (ライセンスがクリーンで精度も高い) |
| **Coqui TTS** | MPL 2.0 | ✅ 可能 | ⭐⭐⭐ | 容易 | **補欠** (開発コミュニティの状態を確認中) |
| **Bert-VITS2** | MIT | ✅ 可能 | ⭐⭐⭐⭐ | 容易 | **検討中** (日本語精度は高いが設定が複雑) |

---

## 3. 推奨選定結果
Aiome では、商用利用が明確に許可されており、かつ微調整（Fine-tuning, LoRA）が容易な **XTTS v2 (Apache 2.0)** を Phase 10.1a の第一候補として統合を進めます。

> **NOTE (商用利用時の重要事項)**:
> - 利用する学習データ自体の権利については `docs/legal/voice_upload_terms.md` に従うものとします。
> - 商用目的で「特定人物の声」を販売・配信する場合、その人物とのライセンス契約が別途必要です。
