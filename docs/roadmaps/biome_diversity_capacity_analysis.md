# Biome 形状多様性の上限検証 — 2D/3D形状アルゴリズム導入時に何種確保できるか

- **ステータス**: 分析・検証（実装ではない）
- **作成日**: 2026-07-04
- **問い**: 2Dと3Dの形状アルゴリズムを Biome に取り込むと、どの程度の多様性が見込めるか。人間が視認して特徴を認識できる個体差を維持しつつ、バリエーションを最大化するなら何種か。ポケモン型の「珍しい/珍しくない」を成立させる前提で徹底検証する。
- **関連**: `docs/roadmaps/biome_lenia_overhaul_plan.md`（Lenia転換計画）

---

## 0. 結論（先に数字）

| 階層 | 定義 | 現実的な目標数 | 根拠 |
|---|---|---|---|
| **科（Archetype）** | 一目で「別種の生き物」と分かるシルエット＋対称性＋挙動のクラス | **30〜50** | Lenia 実測18科 + 反応拡散/離散CAの追加科 |
| **種（Species）** | 同科内で、熱心な収集者が名前で区別できる差異 | **600〜1,500** | 科あたり15〜30種。Lenia 実測400種は探索途上の下限 |
| **個体（Morph）** | 配色・微細な非対称など「色違い/個体値」層 | 実質無制限（レア度ゲートに使う） | 視覚記憶の上限は約22.8万コードで律速しない |

**推奨ヘッドライン数字**: 収集対象として提示する「見分けられる形」は **約800〜1,000種**。これはポケモン規模（約1,000種）と一致し、視覚記憶の実験的上限（2,500）に十分収まり、「一目識別」の限界を超えない。ここに色違い層（×約5）を掛けて **総コレクション項目 約4,000〜5,000**、ただし異なるシルエットは約1,000に保つ、という構成が最適です。

## 1. 多様性を「3階層」で分けて数える理由

生の多様性（パラメータ空間）はどのCAでも実質無限（連続）です。しかしゲームで意味を持つのは「人間が区別できる数」だけなので、次の3階層に分解して数えます。ポケモンの構造と一対一で対応します。

- **科 = タイプ/系統**（ほのお系・みず系のような大分類。約18タイプ）
- **種 = ポケモン種**（ピカチュウ/ライチュウのような「別デザイン」。約1,000種）
- **個体 = 色違い/個体値**（同じ種の希少カラー・微差。無数）

Lenia の論文自身がこの階層（科→種→個体）で分類しており、ゲーム設計にそのまま流用できます。

## 2. アルゴリズム別・多様性の実測と見積り

### 2.1 二次元（2D）

| アルゴリズム | 実測/文献の多様性 | 見分けられる科 | 見分けられる種（見積り） | 備考 |
|---|---|---|---|---|
| **Lenia（連続CA・中核）** | 400種超 / 18科（Chan 2019、探索途上の下限） | 18 | **400〜700** | 幾何学的・分節的で個体差が視覚に出やすい。収集ゲームの原型 |
| **マルチチャンネル/マルチカーネル Lenia** | 自己複製・多形生物・「仮想真核生物」を追加発見 | +5〜10 | **+300〜500** | チャンネル間相互作用で色と挙動の軸が増える |
| **反応拡散（Gray-Scott）** | Pearson 12型 → 拡張17型 | 8〜12 | **80〜150** | 斑点/縞/迷路/波。テクスチャ多様性の供給源 |
| **Larger-than-Life / 連続近傍離散CA** | 数百の「興味深いルール」がカタログ化 | 5〜10 | **50〜100** | グライダー等の「動く形」を供給 |

**2D 小計（重複除去後）**: 見分けられる科 **約25〜35**、種 **約700〜1,100**。

### 2.2 三次元（3D）

| アルゴリズム | 実測/文献の多様性 | 見分けられる科 | 見分けられる種（見積り） | 備考 |
|---|---|---|---|---|
| **3D Lenia** | QD探索で470の質的に異なる挙動カテゴリを発見（2026）。安定ソリトン確認 | 10〜20 | **300〜470** | 固定18科の分類はまだ無い。動く球・螺旋の蛇など。計算コスト高 |
| **3D 反応拡散** | ジャイロイド/管状/3D斑点など | 5〜10 | **50〜100** | 体積内部構造が加わる |
| **ボクセル形態形成（L-system/space colonization）** | 分岐・サンゴ状構造 | 3〜5 | **30〜60** | 樹枝状の「別クラス感」を供給 |

**3D 小計**: 見分けられる科 **約15〜25**、種 **約400〜600**（ただし後述の認識ディスカウント前）。

### 2.3 なぜ単純合算しないか（3つの割引）

1. **重複**: 3D の斑点は 2D の斑点と「同じ模様の立体版」に見え、別種と認識されにくい。科レベルで約20〜30%が重複。
2. **認識ディスカウント（3D固有）**: 立体はオクルージョン（手前が奥を隠す）と視点依存で、静止画一目での識別率が下がる。3D の見分けられる種を **約0.5倍**に割り引くのが妥当。
3. **非実現/退化**: パラメータ空間の大半はカオスか即死で、安定した「生き物」になるのは薄い多様体上のみ。

## 3. 「人間が見分けられる」上限の理論値

視覚の独立な識別軸を掛け合わせて上限を推定します（2Dの例）。

| 識別軸 | 弁別できる段階 |
|---|---|
| シルエット位相（塊/環/放射星/左右対称/分節/樹枝/格子/斑点野/縞野） | 約9 |
| 対称性の位数（非対称/左右/C3/C4/C5/C6/連続放射） | 実現可能で約5 |
| 突起・葉状部の数クラス（0,1,2,3,4-6,7+） | 約6 |
| 内部テクスチャ（無地/環状/斑点/縞/細胞状） | 約5 |
| 挙動（静止/脈動/滑走/回転/分裂） | 約5 |

素朴な積は 9×5×6×5×5 = 6,750。うち実現・弁別可能なのは経験的に10〜15%程度なので **約700〜1,000種**が「一目で見分けられる」2Dの実効上限です。これは Lenia 実測400種（探索途上）と整合し、上の見積りとも一致します。

3D は点群対称の識別クラス（球状/軸対称/左右/正四面体/立方/螺旋キラル/トーラス＝約7）が新たな軸として加わり上限を押し上げますが、認識ディスカウント0.5で相殺され、**2D＋3D 合算の実効上限は約1,500〜2,000**。ただしゲームで気持ちよく収集できる帯は、その内側の **約800〜1,000** です。

**重要な発見**: 視覚記憶の実験（Brady 2008）では2,500個を87〜92%で識別でき、下限推定は約22.8万コード。つまり **「覚えられるか」は制約にならない**。制約は「収集画面で並べたとき一目で見分けられるか」という弁別性で、これが約1,000で頭打ちになります。

## 4. レア度設計（ポケモン型「珍しい/珍しくない」の成立条件）

「珍しさ」は演出でなく **パラメータ空間の体積（＝出現確率）** に対応させると、数学的に正当かつ収集体験として自然になります。Lenia のパラメータ空間はフラクタル的で、安定種は薄い多様体上にしか存在しません。これがそのまま「レアは薄い＝偶然出にくい」を与えます。

| レア度 | パラメータ空間での位置 | 出現比率（目安） | 例 |
|---|---|---|---|
| Common | 広く安定した領域（対称・単純） | 約60% | 単純な塊・環 |
| Uncommon | やや狭い領域 | 約25% | 放射星・縞 |
| Rare | 特定条件が要る薄い帯 | 約10% | 分節・多葉 |
| Epic | 複数条件の交差点 | 約4% | 自律滑走・回転体 |
| Legendary | カオスの縁・自己複製・特殊対称 | 約1% | 自己複製体・3D螺旋 |
| Prismatic（色違い層） | 任意種の希少リカラー | 0.1〜0.5% | 既存の Prismatic 機構を流用 |

この設計なら「珍しいセル＝視覚的に楽しい＝アルゴリズム的にも美しい（薄い多様体上の安定解）」がご要望どおり一致します。

## 5. 2D と 3D、どう取り込むかの推奨

**推奨: 2D Lenia 場を生成エンジンにし、3D で描画する（＋対称性/向きの軸を追加）。完全な体積3D Lenia は Legendary 帯か後期フェーズに限定。**

理由:
- **計算コスト**: 完全3D Lenia は 3D 3チャンネルで1個体あたり約24,000サイト・105パラメータになり、既存 128×128 グリッドを大きく超える。WASM/ブラウザで多数同時は重い。
- **認識性**: 平面シルエットは一目識別が容易。3D生物はオクルージョンで識別率が下がる。
- **良いとこ取り**: 2D Lenia 場を高さ/押し出し/ボリュームで立体表示すれば「動く3D生物」の見た目を得つつ、識別性とコストを維持できる。向き・立体対称を1軸足すだけで多様性は増える。
- **段階性**: 完全体積3D Lenia は「まれにしか出会えない立体レジェンダリー」として希少性の演出に回せる。実測でも3D安定種の発見は難度が高く、希少性の物語と一致する。

## 6. 最終見積りサマリ

| 指標 | 数字 |
|---|---|
| 見分けられる科（アーキタイプ） | **約40** |
| 見分けられる種（収集対象の「形」） | **約800〜1,000**（実効上限1,500〜2,000の内側） |
| 色違い/個体層を含む総コレクション項目 | **約4,000〜5,000** |
| 実装の中核 | 2D Lenia（＋反応拡散でテクスチャ供給）を3D描画。完全3D Lenia はレジェンダリー限定 |
| レア度の根拠 | パラメータ空間の体積＝出現確率。薄い多様体＝レア |

**要約**: ポケモン規模（約1,000種の見分けられる形）は、2D Lenia を中核に反応拡散・離散CAを補助として足せば十分達成でき、視覚記憶・弁別性の限界にも収まります。3D は「描画は3D、生成は2D」を基本とし、完全体積3Dは希少枠に限定するのが多様性・コスト・識別性のバランス最適です。
