*Last Updated: 2026-05-19*
*Maintained by: motivationstudio, LLC*

## 1. ロゴ体系の全体像

Aiome のロゴは **2つのカラーバリアント** と **4つのサイズタイプ** で構成されています。

### 1.1 カラーバリアント

| ID | 名称 | カラー | 用途 |
|---|---|---|---|
| **Primary** | 瑠璃色 (Ruri Blue) | `#14539A` 系の濃紺 | 明るい背景で使用。LP（明背景セクション）、OGP、SNS、印刷物、法務文書 |
| **Primary-Inv** | 白色 (White / Inverted) | `#FFFFFF` | 暗い背景で使用。LP（ダークモードセクション）、ダークUI、暗色背景のSNS投稿 |

> [!CAUTION]
> **上記2種以外のカラーバリアント（グラデーション等）は存在しません。**
> `transparent/` ディレクトリ配下のファイルはプロダクトUI内専用の実験的アセットであり、LP・SNS・OGP・公式配布物での使用は**厳禁**です。

### 1.2 サイズタイプ

| タイプ | アスペクト比 | 解像度 | 構成要素 | 主な用途 |
|---|---|---|---|---|
| **横長 (Horizontal)** | ≈ 4:1 | 500×120 | ワードマークのみ ("Aiome") | ナビゲーションバー、ヘッダー、メール署名 |
| **正方形 (Square)** | 1:1 | 1080×1080 | グラフィックロゴ + ワードマーク | SNSプロフィール画像、アプリアイコン |
| **OGP** | ≈ 1.91:1 | 1200×630 | グラフィックロゴ + ワードマーク | SNSシェア時のサムネイル (`og:image`) |
| **グラフィックのみ** | 1:1 | 1024×1024 | グラフィックロゴのみ（結晶モチーフ） | ファビコン、ローディング、ウォーターマーク、Hero セクション |

  └─ 暗い背景（黒、ダークネイビー、#0b0b0f 等）

## 4. 禁止事項

> [!CAUTION]
> 以下の行為はブランドの一貫性を損なうため、厳禁です。

1. **許可外ファイルの使用禁止**: §2 に列挙された8ファイル以外のロゴ・画像をLP・SNS・OGP・公式配布物に使用してはならない。`transparent/` ディレクトリ配下のファイル、`public/` に偶然存在する非公式ファイル（`aiome-icon.png` 等）の流用は厳禁。
2. **色の改変禁止**: ロゴの色をカスタムカラーに変更してはならない。提供された瑠璃色・白色のいずれかをそのまま使用すること。
3. **比率の変更禁止**: ロゴのアスペクト比を変更してはならない（縦横の引き伸ばし厳禁）。
4. **プレースホルダー禁止**: 仮画像・ダミーロゴを本番環境や SNS に設定してはならない（キャッシュ汚染によるブランド毀損リスク）。
5. **背景色ミスマッチ禁止**: 暗い背景に瑠璃色ロゴ、明るい背景に白色ロゴを配置してはならない（視認性の著しい低下）。
6. **グラフィックロゴの加工禁止**: 結晶モチーフの一部を切り取ったり、回転させたりしてはならない。
7. **非公式ロゴでの代替禁止**: 「実質的に同じ」「似ている」という理由で §2 以外のファイルを使用することは許可されない。公式8ファイルのみが唯一の正規ロゴである。

## 5. クリアスペース（余白ルール）

ロゴの周囲には、**ロゴ高さの 25% 以上**の余白（クリアスペース）を確保すること。
他の要素（テキスト、画像、罫線等）がこの領域に侵入してはならない。

```
          ┌─── 25% ───┐
          │            │
    ┌─────┤   LOGO     ├─────┐
    │ 25% │            │ 25% │
    └─────┤            ├─────┘
          │            │
          └─── 25% ───┘
```

## 8. LP 用ファイル名対応表

LP（Landing Page）など、ビルドシステム（Vite/TailwindCSS等）の制約でマルチバイト文字列が使用できない環境においては、以下のASCIIファイル名へのリネームを許容します。ただし、実体（MD5ハッシュ）は正規ファイルと完全に同一でなければなりません。

| 正規ファイルID | LP 用ファイル名 | 備考 |
|--------------|---------------|------|
| `white-h` | `aiome-horizontal-white.png` | ヘッダー用 |
| `white-ogp` | `aiome-hero-white.png` | ヒーローセクション用 |
| `white-g` | `aiome-graphic-white.png` | グラフィックのみ |
| `ruri-ogp` | `ogp.png` | OGP メタタグ用 |

## 9. Web 用派生アセット

Web プロダクト（Management Console, LP, Nurture UI 等）において、ブラウザの仕様やビルドツールの要件で公式 PNG の利用が技術的に不適切な場合に限り、以下の派生アセットの使用を公式に認めます。

- **`favicon.svg`** — `white-g` のベクター（SVG）版。全 Web プロダクトの `<link rel="icon">` として使用可能。
