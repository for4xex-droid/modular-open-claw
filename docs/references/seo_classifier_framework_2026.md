## 核心テーゼ

Google の検索アルゴリズムは **道徳的裁定者ではなく、テーブルを読む分類器 (Classifier)** である。
Content Warehouse leak により 14,000+ の特徴量が確認され、DOJ 証言で内部アーキテクチャが裏付けられた。

## 3 軸シグナルモデル

| 軸 | ウェイト | 主要シグナル |
|---|---|---|
| **OnPage (コンテンツ)** | ~1/3 | タイトル、構造化データ、コンテンツ品質 |
| **OffPage (リンク)** | ~1/3 | バックリンク、ドメイン権威、参照元多様性 |
| **User Engagement** | ~1/3 | Navboost (クリックデータ)、滞在時間、直帰率 |

> **重要**: この 3 軸のウェイトは **アップデートごとに変動** する。
> 「コンテンツが王」「リンクは死んだ」「UX だけに集中しろ」は全て誤りである。
> 3 軸への分散投資が 5 年地平線での勝利戦略。

## 戦術評価フレームワーク (3 つの問い)

### Q1: 分類器がクラスタリングできるパターンか？
- **Yes** → その手法には半減期がある。期限を知った上で使え。
- **No** → 複利で効く。スケールせよ。

### Q2: 明日失敗したら、何を失うか？
- 「投じた $1,000」 → 実行
- 「本業全体」 → 実行するな
- **非対称なダウンサイドだけが本当に守るべきもの**

### Q3: アップサイドは他の収益と非相関か？
- 同じアップデートで全滅するポートフォリオは最悪
- **異なるリスクプロファイル + シグナル重複による相互補強** が理想

## Aiome への直接適用

### CCI News エンジン (P4-2)
- 3 軸ウェイトの変動を TimesFM でトレンド予測
- アップデート勝者/敗者の自動分析 → Trend API の核
- 14,000+ 特徴量のうち公開済みシグナルの体系的カタログ化

### 収益ポートフォリオ検証
- 7 収益源の **リスク相関マトリクス** で非相関性を担保
- 同一外部要因 (Google algo, LLM 価格, 規制) での同時死亡を防止

### Aiome 自身の SEO
- AI 生成コンテンツは Q1 で「半減期あり」と判定 → 人間の手を加える
- GitHub SEO (P3-5) は Q2 で「失うもの = 1h 工数」→ 即実行
- YouTube / SNS / GitHub は Google SERP と非相関 → 分散チャネルとして有効

## 哲学的共鳴

> *「道徳ではなく精度。精度だけが利益を生む。」*

これは Aiome の TLA+ 形式検証の哲学と響き合う:
- TLA+ は「正しいと信じる」のではなく「数学的に証明する」
- SEO も「ガイドラインに従えば報われると信じる」のではなく「分類器の入力を最適化する」
- **信念ではなく、測定可能な精度で勝負する**
