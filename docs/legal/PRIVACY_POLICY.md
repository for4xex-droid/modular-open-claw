# Aiome 仮想通貨・データプライバシーポリシー (Privacy Policy)

**最終更新日**: 2026-04-12

本プライバシーポリシー（以下「本ポリシー」）は、セルフホスト型 AI オペレーティングシステム「Aiome」（以下「本ソフトウェア」）が取り扱うデータの性質、および利用者が本ソフトウェアを稼働させる際（以下「運営者」または「ユーザー」）のデータ保護方針について定めます。

## 1. 原則（The Principle of Local-First）

Aiome は、**プライバシー・バイ・デザイン（Privacy by Design）** および **ローカルファースト（Local-First）** の設計原則に基づいて構築されています。
本ソフトウェアによって生成、収集、または保存されるデータは、原則として**本ソフトウェアが稼働しているインフラ環境内（ローカルホストまたは所有者のサーバー）で完結し、開発者（モチベーションスタジオ LLC）へは一切送信されません。**

## 2. 収集されるデータの種類と保存場所

本ソフトウェアは以下のデータをシステム内でローカルに保存（SQLite）します。

*   **アカウント情報**: エージェントID、認証キー
*   **通信記録（チャットログ）**: ユーザーと AI エンティティ（Samsara / Cortex）とのチャット履歴、思考プロセスログ (`trajectory_store` 等)
*   **アセットデータ**: アップロードされた音声バインダー (.aivoice), アバターモデル (.inx), ドキュメント知識
*   **監査ログ・システムのヘルスデータ**: エラーログ、コスト消費履歴 (`resource_usage_logs`)

**これらのデータはすべて、運営者が指定するローカルの永続化ボリューム（通常 `./data/` 配下）に保存されます。**

## 3. 外部サービスとの通信におけるデータの取り扱い

Aiome は、LLM 推論や外部リソースの取得のため、運営者が設定した場合にのみ以下の外部 API と通信します。

*   **LLM プロバイダー (Claude, OpenAI, Gemini, Fal.ai 等)**: 
    *   送信内容: 推論に必要なプロンプト、システムプロンプト、および必要な対話の文脈（チャット履歴）。
    *   取り扱い: 各プロバイダーの利用規約（API 経由での送信は学習に利用されない等）に依存します。本ソフトウェアを実行する運営者は、各プロバイダーに送信されるデータの内容に責任を持ちます。
*   **コマースおよび連携 (Stripe, Tremendous等)**:
    *   決済情報やギフト送付処理のためのパラメーター通信。
*   **P2P Federation (Samsara Hub)**:
    *   Samsara Hub 経由でのトレンド・自律的パブリッシュ（WordPress 等への投稿）を行う機能。公開設定された情報のみが送信されます。

**運営者は、機密情報（個人情報 PII、パスワードなど）を含むデータをプロンプトに含めないよう、システム側のマスキング設定（`guardrails` の PII マスキングなど）等を通じて適宜コントロールする責任を有します。**

## 4. データの削除（忘れられる権利 / GDPR準拠）

Aiome は、全データがデータベース内の単一または特定のテーブルに関連付けられているため、環境の初期化（`FactoryReset`）または該当リソースの削除 API の実行を通じて、**利用者が自らの意志でサーバー内からデータを完全に物理削除（CASCADE DELETE またはディレクトリ破棄）することが可能です**。

## 5. 個人特定情報 (PII) のマスキング方針

本ソフトウェアは、アプリケーションのログ（`tracing` イベント経由）において、クレジットカード番号等をマスクするフィルター機能を出荷時に実装・提供していますが、すべての PII の漏洩を防ぐことを 100% 保証するものではありません。

## 6. 免責事項

モチベーションスタジオ LLC（Motivation Studio LLC）は、**運営者が管理する本ソフトウェアのインスタンス内で処理・保存されたデータの漏洩、消失、改ざんなどのインシデントについて、一切の責任を負いません**。
バックアップ・リストア運用、データベースアクセスへの適切なアクセス権限の設定は、すべて運営者の責任において実施してください。

## 7. 変更について

本ポリシーは、システムの機能追加等に伴い改定される場合があります。最新版はリポジトリまたはリリースノートにてご確認ください。
