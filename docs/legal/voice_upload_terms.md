# 音声アップロードおよび利用に関する規約

Aiome（以下「本システム」）において、音声データ（以下「本データ」）をアップロード、またはそれに基づく LoRA (Low-Rank Adaptation) 学習を行う際、ユーザーは以下の事項に同意するものとします。

## 1. 権利の保証
- ユーザーは、アップロードする本データが**ユーザー自身の音声**であること、または権利者から本システムでの利用（AI学習および音声合成を含む）について**明示的な許諾を得ていること**を保証します。
- 第三者の音声を無断でアップロードし、その人物に成り代わるような音声合成を行うことは、パブリシティ権および肖像権の侵害となる可能性があり、固く禁じます。

## 2. 利用目的
- アップロードされた本データは、以下の目的でのみ利用されます。
    - ユーザー専用の LoRA モデルの作成（学習）
    - 音声合成（TTS）によるコンテンツ生成
    - 本システム内での AI キャラクターへの適用

## 3. 禁止事項
- 犯罪行為、公序良俗に反する行為、または他者を誹謗中傷する目的での音声合成。
- 権利者に無断で作成されたクローン音声による、なりすましや詐欺行為。

## 4. 免責事項
- 本データおよび生成された音声に起因する第三者との紛争について、本システムおよび開発者は一切の責任を負いません。
- 二次創作や商用利用に関しては、選択した TTS Provider のライセンス条項が別途適用されます。
