# Karma Coins (KC) の法的位置づけ

**版**: v1.0
**最終更新日**: 2026-07-22
**性質**: 社内正本（公開規約への反映は `TERMS_OF_SERVICE.md` §4 を参照）

## 1. 結論

**Karma Coins（KC）は無償で付与されるアプリケーション内ポイントであり、資金決済に関する法律（資金決済法）第 3 条の前払式支払手段に該当しない。** 当社は KC を有償で販売せず、KC と法定通貨・財産的価値との交換も行わない。

## 2. 判断根拠

前払式支払手段の該当要件は概ね (1) 金額等の財産的価値が記載・記録されること（価値の保存）、(2) 金額・数量に応ずる**対価を得て**発行されること（対価発行）、(3) 発行者等に対する代価の弁済等に使用できること（権利行使）の 3 要件である。

KC は現行実装において:

* **対価発行の否定**: KC を法定通貨で購入する経路は存在しない。Stripe Checkout は Pro サブスクリプション（`mode=subscription`）のみを生成し（`libs/aiome-commerce/src/stripe/mod.rs` `create_checkout_session`）、法定通貨→KC のチャージ導線は封印されている。KC は Pro 特典の月次含み枠（`pro_monthly_kc_allowance`）等、**対価と紐付かない付与**のみで発行される。
* **換金性の否定**: KC を現金・その他の財産的価値へ払い戻す機能は存在しない。

よって (2) を満たさず、前払式支払手段に該当しない（いわゆる「無償ポイント」）。

## 3. 現行実装との対応（監査ポイント）

| 実装 | 状態 | 逸脱時のリスク |
|---|---|---|
| `create_checkout_session` が subscription mode 固定 | ✅ 封印 | 一回払い（`mode=payment`）で KC を販売すると対価発行に該当 |
| `execute_autonomous_purchase` → Nurture `/internal/purchase`（OP-011） | ✅ **無償 KC マーケット購入のみ解禁**（本番 `!is_mock` + Nurture S2S。Desktop は Bridge 直） | 有償 KC チャージや法定通貨での代理決済に拡張すると資金決済法・特商法の再評価が必須 |
| Webhook `checkout.session.completed` の `asset_id` 経路（コイン加算） | ⚠️ コードは存在するが到達不能（アセット有償販売導線が非公開） | 導線を公開すると KC 建て有償販売＝資金決済法・特商法の再評価が必須 |
| UI の「チャージ」文言（VoiceStore 等） | ⚠️ 是正対象（OP-084 L1-1 / 本計画 G-12） | 「購入できる」誤認を与える表示は不当表示リスク |

## 4. 有償化する場合の解除条件（将来）

KC の有償販売（チャージ）を開始する場合、**開始前に**以下をすべて完了すること:

1. 資金決済法の該当性再評価（自家型前払式支払手段としての届出要否。基準日未使用残高 1,000 万円の閾値管理 = `MAX_TOTAL_OUTSTANDING_COINS` ハードキャップの実装）
2. 表示義務（法第 13 条: 発行者名・支払可能金額・有効期間・問い合わせ先・利用範囲・利用上の注意・未使用残高の確認方法等）のアプリ内表示
3. 利用規約・特商法表記・本書の改定と周知
4. チャージ同意 UX（`commercial/docs/legal/CHARGE_UX_CONSENT.md`）と TOS コア条項（`commercial/docs/legal/TOS_CORE_DRAFT.md`）の弁護士レビューと組み込み
