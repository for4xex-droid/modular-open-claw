# build.rs セキュリティ監査ログ

## 1. 方針
Rust の `build.rs` はビルドプロセス中に任意の OS コマンドを実行できる強力な権限を持っています。サプライチェーン攻撃を避けるため、本プロジェクトでは以下のルールを徹底します。

| `pyo3-bridge` | Python 共有ライブラリの自動検知 | 2026-03-14 | 創業者 | ✅ 安全 |

## 3. 変更禁止ルール
- 新規の `build.rs` 追加は、ADR での議論と、創業者によるコード一行ごとの詳細レビューが必須。
- 外部ネット通信を行う `build.rs` は原則禁止。
