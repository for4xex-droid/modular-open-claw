# ADR-006: PyO3 によるサンドボックスの設計

## ステータス
Accepted

## コンテキスト
AI エージェントが自由な Python コードを実行できる柔軟性と、ホストシステムへの攻撃を防ぐ安全性を両立させたい。

## 決定
PyO3 を用いて Python インタプリタを埋め込み、OS レベルの制限（setrlimit）を併用する。

## 理由
1. **Python の圧倒的シェア** — AI 開発において Python 以外の選択肢は現実的でない。
2. **パフォーマンス** — プロセス起動オーバーヘッドを避け、Rust 内で Python コードを直接制御。
3. **多層防御** — Python インタプリタ内の制限だけでなく、`setrlimit` で CPU 時間やメモリ、ファイルアクセスを物理的に制限。

## 影響
- Shared Library の依存関係により、バイナリの配布が複雑になる可能性がある。
- GIL (Global Interpreter Lock) の管理に注意が必要。
