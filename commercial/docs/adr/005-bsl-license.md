# ADR-005: BSL 1.1 ライセンスの選択

## ステータス
Accepted

## コンテキスト
コアプロトコルを公開しつつ、大手クラウドプロバイダーによるタダ乗り（マネージドサービス化）を防ぎ、ビジネスの持続可能性を確保したい。

## 決定
Business Source License (BSL) 1.1 を採用する。

## 理由
1. **将来のオープンソース化** — 一定期間（Change Date）経過後に Apache-2.0 または MIT に自動移行することを約束し、コミュニティの信頼を得る。
2. **商用利用のコントロール** — 競合他社による再配布やマネージドサービス提供を制限しつつ、一般ユーザーの利用は許可（Additional Use Grant）。
3. **投資家へのアピール** — 独自 IP の保護が明確であり、買収時の評価額（Valuation）を高める。

## 影響
- ライセンスヘッダーの厳格な管理が必要。
- 依存する OSS ライブラリのライセンス（GPLなど）との両立性に注意が必要。
