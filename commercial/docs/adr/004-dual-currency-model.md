# ADR-004: 二重通貨モデル (AiomeCoin + CreatorPoints)

## ステータス
Accepted

## コンテキスト
決済手段としての安定性と、エコシステム貢献へのインセンティブ設計、および法的リスク（資金決済法）の分離を両立させたい。

## 決定
AiomeCoin（決済用、前払式支払手段）と CreatorPoints（評価・インセンティブ用、非金銭スコア）の二重通貨制を採用する。

## 理由
1. **法的リスクの分離** — AiomeCoin は供託等の法的義務が伴うが、CreatorPoints は純粋な技術的報酬スコアとして扱い、規制を回避する。
2. **インセンティブ設計** — 開発者やAIエージェントの貢献をポイントで評価し、それを AiomeCoin の分配等に利用可能とする。
3. **価値の安定** — 決済用通貨に複雑なインセンティブロジックを混ぜることを避け、台帳の整合性をシンプルに保つ。

## 影響
- 二つの独立した台帳管理ロジックが必要。
- ポイントからコインへの交換所（Marketplace）の設計が必要。
