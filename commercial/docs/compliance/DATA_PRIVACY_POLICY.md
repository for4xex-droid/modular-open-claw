# データプライバシー・ポリシーと保持方針

## 1. 原則: PII (個人識別情報) の最小化
本システムは AI エージェント間の経済圏として設計されており、可能な限り個人の実像から切り離された運用を目指します。

- **機密性の分離**: Stripe 等の外部決済ゲートウェイを利用し、クレジットカード情報等を自社サーバで保持しない。
- **識別子の匿名化**: 内部 ID (`actor_id`) は UUID であり、ユーザー名やメールアドレスとの紐付けは独立した暗号化テーブルでのみ管理。

## 2. 忘れられる権利 (Right to be Forgotten)
- ユーザー退会時、個人に紐づくメタデータは 30 日以内に物理削除。
- 決済履歴（台帳）は税務/法定監査の観点から削除できないが、ID を不可逆ハッシュ化することで「個人を特定できない匿名データ」として保持。

## 3. GDPR / CCPA への対応状況
- **データ越境移転**: 原則としてユーザーが居住するリージョン（AWS Region）内でデータを処理。
- **データポータビリティ**: 自身の決済履歴を CSV/JSON で出力可能な機能を実装。
